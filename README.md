# 思惟力量會議助手

## 本版更新

- **原始檔名與資料夾**：會議逐字稿上方顯示實際原音檔名與 Music 錄音資料夾，可複製完整路徑。修改會議標題後仍可對照。

- **Google Gemini API**：新增 Google AI Studio Key 設定、模型清單、一般分段轉錄、說話人分離與會議摘要，同一服務共用加密儲存的 Key。
- **說話人與姓名**：依聲音分組，逐字稿顯示說話人，可手動修改姓名；複製、匯出與新摘要帶入姓名。
- **本機摘要準備**：首次設定一起下載 Whisper Small 與 Qwen 3.5 4B，實際載入檢查後才完成；設定頁與會議摘要設定可下載模型、查看進度、取消與重試。
- **使用手冊恢復**：完整包附 17 頁 Word 操作手冊，保留 12 張原有截圖，補上本機設定、錄音中心、姓名修改與 Gemini 說明。
- **錄音與轉錄中心**：沿用集中聆聽、搜尋、工作進度、各筆取消／接續及雲端 3 筆、本機 1 筆的處理流程。

Google 說話人模式限 30 分鐘、最多 8 位，3 人以上仍屬實驗性。OpenAI 相容說話人模型公告於 2027/02/26 停用。姓名與時間資訊仍須對照原音確認，詳見[操作說明](操作說明.md)。

升級請先關閉舊程式，再執行包內「啟動_先備份.ps1」。保留既有資料識別碼；排隊狀態不跨程式重開保存，已建立會議的分段進度可接續。不要把私人錄音、資料庫或 API Key 上傳 GitHub。

## 核心流程

錄音或匯入音檔 → 保留原始音檔 → 完整分段轉錄 → 儲存逐字稿 → 依設定產生摘要 → 查看、播放與匯出。

## 功能

- **實體與線上會議**：實體會議錄製麥克風；線上會議錄製麥克風與電腦播放聲音，可選擇錄製指定視窗，或只錄聲音。
- **完整音檔轉錄**：停止收音後先儲存原音，再進行音訊轉換與分段辨識；也可匯入既有音檔。
- **本機與雲端混搭**：語音轉逐字稿、逐字稿產生摘要分開選服務與模型，例如本機 Whisper 轉錄、OpenAI 摘要，或 Groq 轉錄、Claude 摘要。
- **統一服務設定**：管理內建 AI、Google Gemini、Claude、自訂 OpenAI 相容伺服器、Groq、Ollama、OpenAI、OpenRouter。文字與音訊端點分開測試；語音選單依服務的音訊能力提供。
- **Key 只設定一次**：同一服務的轉錄與摘要共用連線設定，API Key 遮蔽顯示，使用 Windows DPAPI 加密儲存。
- **一鍵接續處理**：可設定轉錄完成後自動產生摘要；摘要失敗時可單獨重試，保留已完成的逐字稿。
- **原音與逐字稿對照**：內建播放器，點逐字稿時間跳到對應原音，可開啟錄音資料夾、重新轉錄及匯出 TXT／Markdown；匯出檔名帶入會議名稱。
- **模型清單與摘要範本**：文字模型提供建議選項及重新載入清單，並保留自訂模型 ID；五種範本依所選語言的自然用詞產生內容。
- **繁體中文介面**：設定、處理階段、錯誤及操作提醒使用中文；摘要語言可另外選擇。

## 五種摘要範本

| 範本 | 整理內容 |
| --- | --- |
| 一般會議紀要（預設） | 會議摘要、詳細討論、決議、任務與負責人、時間及預算、待確認事項 |
| 團隊回顧與改善 | 目標與成果、做得好的地方、問題與原因、改善決議及追蹤任務 |
| 客戶／合作洽談 | 客戶需求、提案與合作範圍、金額與條件、雙方承諾及後續跟進 |
| 訪談整理 | 受訪者觀點、問答、案例、重要原話及後續問題 |
| 課程／演講筆記 | 核心概念、方法步驟、案例、數字及複習重點 |

## 相較原 Meetily 社區版的改造重點

沿用 Meetily 的桌面程式、會議管理、轉錄及摘要基礎，本版集中調整以下流程：

| 項目 | 本改造版的調整 |
| --- | --- |
| 錄音與轉錄順序 | 改為先保存原始錄音，停止後再以完整音檔分段轉錄，避免錄音期間重複辨識。 |
| 長音檔處理 | 統一錄音與匯入音檔的完整轉錄流程，保留分段時間資訊及重新轉錄入口。 |
| AI 設定 | 將各服務連線集中管理，轉錄與摘要分開選模型，同服務共用 Key，支援跨服務搭配。 |
| 摘要內容 | 重寫五種英文 Prompts，直接依所選語言產生；區分決議與未決提議，缺少負責人或期限時保留待確認。 |
| 本機摘要 | 簡化本機提示詞、依原文長度調整輸出上限，修正已知中文標題與任務漏列問題。Qwen 2B 設定以已下載的 4B 品質模式產生紀要。 |
| 操作體驗 | 中文化設定與提示，加入錄音後下一步提醒、模型清單、原音播放器及帶會議名稱的匯出檔名。 |
| Windows 使用 | 完整包附 FFmpeg，解壓後即可啟動主程式，不需另外執行 FFmpeg 準備腳本。 |

## 第一次使用

1. 下載完整 ZIP，完整解壓至可寫入資料夾，執行 `ThinkingPowerMeeting.exe`。需要 Windows x64 與 WebView2 執行階段。
2. 首次按「準備本機轉錄與摘要」，下載 Whisper Small（約 466 MB）與 Qwen 3.5 4B（約 2.6 GB）並完成載入檢查，合計約 3.1 GB。建議至少 16 GB 記憶體及 5 GB 可用磁碟。已有模型會沿用；之後可在設定切換本機或雲端服務，雲端使用自己的 API Key。
3. 選實體／線上會議並確認收音裝置，或按「匯入音檔」。
4. 停止錄音後等待原音保存及轉錄；選擇摘要範本、語言，按「產生摘要」，或啟用自動摘要。
5. 播放原音核對內容，再匯出逐字稿或 Markdown。

模型權重另行下載。Qwen 4B 約 2.7 GB；缺少模型時程式會提示下載，不會自行切換至雲端。雲端轉錄與摘要分別依服務計費，ChatGPT 訂閱不包含 API 用量。AI 產生的人名、數字、任務與決議請對照原音核對。
